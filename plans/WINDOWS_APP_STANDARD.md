# Windows app standard for every SIR product (owner, 2026-11-11)

1. A real installed program, not a website shortcut: package with Electron (or Tauri) using electron-builder, producing a normal Windows installer (NSIS `.exe`), Start menu entry and Desktop shortcut with the product's own icon. Add a portable build when useful. If a product needs bundled extras (runtimes, sample files), ship them inside the installer.
2. Signed in and connected: the same Google sign-in as the web app, through Firebase Auth, same account and data everywhere; keep a local offline queue for actions made without a connection.
3. Always the latest build: the Desktop shortcut launches a small launcher that starts the current installed version, and the app checks for updates itself (electron-updater) against the product's own release feed. A project script builds a fresh installer and the project's "Product Kit" folder always holds the newest one.
4. Download page: the product's website has a Download section listing the Windows installer, the Android APK or Play Store link, iOS (TestFlight or "Install as app"), and macOS/Linux builds once they exist, each with its version, file size and checksum.
5. Normal release hygiene: keep the repository private, ship production builds only (minified, no debug source maps in the public release), and keep real secrets and business rules server-side rather than in the client bundle, the same baseline any commercial desktop app follows. A code-signing certificate is a purchase for the owner to make later (note it in OWNER_ACTIONS when relevant).
6. Per-project "Product Kit" folder (`D:/Projects/<Project>/Product Kit/`): shortcuts to the Firebase host, the Vercel host, the local dev server, the Windows app launcher, the Vercel deployments page, the Firebase project overview, and the private repo; the newest installer, APK or IPA when they exist; a short README describing each file. This folder holds links and built artifacts, not source code.
7. A project hub page (`D:/Projects/Projects-Hub.html`) lists every project with all its links (hosts, local dev, repo, Vercel deployments, Firebase overview, analytics, docs) and an "Open all" action per project, reachable from one Desktop shortcut.
