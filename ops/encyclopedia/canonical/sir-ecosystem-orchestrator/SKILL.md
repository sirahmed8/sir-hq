## 1. The 10 Active Core Pillars

All agent actions, architectural refactors, and code modifications across Sir Ahmed's ecosystem must adhere strictly to these 10 non-negotiable principles:

1. **Core Workflow Protocol (Analyze -> Plan -> Approve -> Execute -> Verify -> Document)**:
   - Always analyze first with live intelligence (`search_web`, `read_url_content`).
   - Create structured plans with verifiable checkpoints. Seek alignment before modifying code.
   - Execute with zero placeholders (`// TODO`), zero mock data, and complete types.
   - Rigorously verify via unit tests, typechecking, and Chrome DevTools MCP.
   - Maintain living `walkthrough.md`, `README.md`, and `ARCHITECTURE.md` documentation.

2. **Token-Smart Engineering & Zero-Waste Protocol**:
   - Utilize AST knowledge graphs and deterministic path mapping.
   - Surgical file navigation via `grep_search` and targeted slice reading (`view_file`).
   - Surgical file modifications with `replace_file_content` — never overwrite entire files.
   - Zero chat redundancy: concise summaries and clickable references.

3. **Senior Multi-Platform Engineering & Anti-Monolith Standard**:
   - Strictly prohibit single-file monolithic applications.
   - Enforce 4-tier separation: Presentation Layer, Domain/State Layer, Data Layer, and Core Layer.
   - Maintain platform rigor: React 19 / Vite 6 / Next.js 16 (strict TS), .NET 9 MVVM, FastAPI + Pydantic v2.

4. **Automatic Skill & MCP Activation**:
   - Proactively map and route to specialized skills (`taste-design-engine`, `production-engineering-standards`, `owasp-vulnerability-shield`, `meta-social-sidecar`, `pc-storage-guardian`).
   - Use browser automation via Chrome DevTools MCP for visual verification.

5. **Philosophical, Scientific & Psychological UI/UX Standards**:
   - Radical creativity: eliminate AI design clichés (no neon purple gradients, no generic pill buttons, no placeholder metrics).
   - Color theory: strict 60-30-10 palette with oklch/hsl uniform lightness.
   - Ergonomics (HCI laws): Doherty threshold (<400ms feedback), Hick-Hyman, Fitts's law (44x44px targets), Miller's law.
   - 5-State completeness: Initial, Loading (skeletons), Empty, Error, and Overflow states.

6. **Production Engineering, Database Resilience & Zero Fake Data**:
   - Real persistent storage (PostgreSQL, SQLite, Firebase Firestore, structured localStorage).
   - Strict runtime schema validation (Zod, Pydantic v2).
   - Atomic transactions with rollback, client idempotency keys, and indexed queries.

7. **Zero-Trust Security, Auth & Vulnerability Hardening**:
   - HttpOnly, Secure, SameSite cookies.
   - Role-Based Access Control (RBAC) and Row-Level Security (RLS) tenant isolation.
   - Strict query parameterization, CSP headers, rate-limiting, and sanitized inputs.

8. **Legal Compliance, Privacy, SEO & Discoverability**:
   - Dedicated `/privacy`, `/terms`, `/refunds`, and `/cookies` routes.
   - Generative Engine Optimization (GEO) and JSON-LD structured schemas (`Organization`, `WebSite`).
   - Dynamic sitemaps, clean semantic markup, and custom branded 404/500 error pages.

9. **Quality Assurance, Observability & Zero-Bug Philosophy**:
   - Global Error Boundaries, graceful toast notifications, and retry triggers.
   - Centralized structured JSON logging, `/api/health` endpoints, and zero unhandled console warnings.

10. **Task Continuation & Error Recovery Protocol**:
    - Living `continuation_checkpoint.md` recording exact step, last action, and immediate next action.
    - Model-agnostic recovery across context resets or interruptions.

## 3. Ecosystem Health Verification Commands

Run these verification commands to validate workspace integrity:

```powershell
# 1. Audit Git status across all repositories
Get-ChildItem -Path "D:\Projects" -Directory | ForEach-Object {
    if (Test-Path "$($_.FullName)\.git") {
        Write-Host "Checking $($_.Name)..." -ForegroundColor Cyan
        git -C $_.FullName status --short
    }
}

# 2. Run Vitest suites for flagship web applications
npm --prefix "D:\Projects\SIR Library" test -- --run
npm --prefix "D:\Projects\SIR Pharmacy" test -- --run

# 3. Verify clean production builds

npm --prefix "D:\Projects\SIR Pharmacy" run build

# 4. Storage and system telemetry health check
```
