# social-creator-studio

## Summary
social-creator-studio is a SIR-authored content-production skill for short-form social media, built on "52 creator frameworks" distilled into five modules: Reels/Shorts scripting with a timed hook-agitation-payoff-CTA structure, a 10-slide viral carousel formula, caption psychology, a 4-line bio/profile conversion audit, and comment-to-DM funnels. It is pure methodology text: formulas, timings and copy patterns the agent applies when writing content; it contains no posting automation, no platform API calls and no media generation.

## When to use / when NOT
Use when the owner asks for a Reel/Short script, carousel outline, post caption, bio rewrite or DM-funnel copy for Instagram/TikTok-style content. Do NOT use it to actually publish posts (that needs platform credentials and the owner's accounts), to design the carousel visuals (that is a design/image task), or for long-form articles.

## Inputs, outputs, tools
- Inputs: the product/audience/topic and the requested format (script, carousel, caption, bio, funnel).
- Outputs: Markdown/text content: timed script beats, per-slide carousel copy, caption drafts, bio lines, funnel copy.
- Tools: none; it is instruction text. Pair with imagegen/motion-graphics-engine for visuals and meta-social-sidecar for publishing.

## 5 most important rules
1. Reels structure is timed: 0-3s visual hook, 3-15s problem agitation, 15-45s high-signal breakdown, 45-60s conversion CTA.
2. Carousel slide 1 must pass the 2-second glance test; slides 4-7 carry one actionable idea each; slide 9 is a screenshot-worthy cheat sheet; slide 10 is the save/share CTA.
3. Captions: the first line must hook before the "...more" fold; short paragraphs; end with a comment-provoking question.
4. Bio audit is exactly 4 lines: positioning, verifiable metric/proof, lead magnet, link CTA.
5. Every module pushes a keyword-comment CTA ("Comment X and I'll send you the template") feeding the DM funnel.
