## 2. Real user complaints (patterns, each marked by source quality)

- Paywall hostility: "job seekers who are unemployed cannot afford USD 50/mo to check a resume" (r/jobs, widely repeated; specific thread not traced, "(unsourced, verify)").
- Cloud CV custody: phone, address and employment history on third-party trackers leads to recruiter spam and cold sales (multiple Trustpilot/Reddit threads; not traced one-by-one, "(unsourced, verify)").
- Generic/hallucinated cover letters inventing senior titles (r/recruitinghell pattern; not traced, "(unsourced, verify)").
- Auto-apply spam: recruiters report obviously mass-applied candidates are auto-rejected (community consensus; not a single citable URL, "(unsourced, verify)").
- Free tiers that are theater: scan caps (Jobscan), job caps (Huntr 100), tailored-resume caps (Teal/Huntr 2) (official pricing pages, 2026-11-12, verified).
- Account bans from ToS-violating automation (community reports on LazyApply-class tools; not traced, "(unsourced, verify)").

## 3. "We Do Better" advantage map (SIR Jobs)

1. **Private by architecture.** Local Node server on 127.0.0.1:3456, Tailscale-only remote, SQLite local store. CV, phone, address, notes never leave the machine; outside AI sees public job text only (redaction test enforced).
2. **Free, forever, for one owner.** No subscription, no credits, no scan caps, no job caps. Local ATS-style keyword scoring with a written rubric, not a black-box magic number.
3. **Truthfulness by construction.** Drafts constrained to the verified sophomore profile and real portfolio; second-pass truth audit blocks invented seniority; no application counted "Applied" without a proof file (screenshot, email id or confirmation URL).
4. **Auto-apply, but vetted.** Owner decision 2026-11-11: automatic application to vetted truthful matches only, cap 10 per day, dedupe by URL, 15 skip rules (graded test, ID upload, payment, unverifiable poster, whatsapp-only, upfront fee, experience mismatch, outside profile, truth-audit fail...), Telegram report of every application and every first answer.
5. **Arabic-first reach.** Wuzzuf, Mostaql and Arabic remote boards as sources (official feeds or manual import only, per-source terms review); Arabic RTL everywhere; Arabic digest in simple Egyptian Arabic.
6. **Income measured, not imagined.** `.sir/INCOME_MODEL.md` (2026-11-11) researches real Vibe Coder rates (DataAnnotation USD 20-50/hr class, Upwork prompt roles median ~USD 50/hr, Arabic evaluator premium); no fixed income goal; reports real numbers only.
7. **Fallback chain.** Gemini flash-lite then flash then any Gemini, then OpenRouter free, then local Ollama (`D:\Projects\AI_Models_Hub`); kill switch `JOBS_AI=off`; eval set gates model swaps.
8. **Owner-side control.** Every submission the owner can veto; proof ledger; follow-up nudges; interviews synced only with the owner's tap.
