# Video understanding tools, compared (2026-11-12)

What was checked on this PC and what each option does for "watch this TikTok/Reel/Short for me". Headless = runs without a browser or login on Windows.

1. **yt-dlp 2026.10.26** (winget, `C:\Users\a7med\AppData\Local\Microsoft\WinGet\Links\yt-dlp.exe`): downloads video+audio from YouTube, YouTube Shorts, TikTok, Instagram (public posts), X, Facebook and 1000+ sites. Unlicense (public domain). Headless: yes. Limits: TikTok and Instagram sometimes need `--cookies-from-browser chrome`; YouTube may throttle datacenter IPs but works on this residential connection.
2. **agent-reach 1.6.0** (`C:\Users\a7med\.local\bin\agent-reach.exe`, skill in `.claude/skills` and `.agents/skills`): read-only platform reader. Has `youtube subtitle/transcribe` and `instagram posts`, no TikTok channel, returns text only (subtitles, captions, post text), never video frames or audio transcription of its own. Good first try for YouTube because captions are free and instant; wrong tool when the owner sends a TikTok or an Instagram Reel where captions are absent.
3. **ffmpeg/ffprobe 8.1.1** (winget full build): extracts audio (16 kHz mono wav/mp3) and grabs frames at exact timestamps. GPL/LGPL build, free. Headless: yes. This is the backbone every pipeline needs; no limits.
4. **Groq `whisper-large-v3-turbo`** (API, `GROQ_API_KEY` in `_local/api-keys.env`): cloud transcription, fast (a 60 s clip in about 1-3 s), free tier, auto language detection, JSON response. Headless: yes, plain HTTPS POST. Limits: file size cap about 25 MB per request and per-minute request caps on free tier; noisy music-only clips return empty text.
5. **faster-whisper 1.2.1** (`C:\Users\a7med\AppData\Local\Python\bin\python.exe`, MIT license): local transcription fallback. Models `faster-whisper-tiny` and `faster-whisper-base` already in the HF cache. Headless: yes. Limits: needs that specific Python (the default `python` on PATH has no faster_whisper); CPU transcription of a 60 s clip takes roughly 10-30 s on this laptop; quality below Groq's large-v3-turbo.
6. **OpenAI whisper (legacy copy)** in `D:/Projects/SIR AI/legacy/agentic-os-research/whisper`: source tree only, no installed environment, needs PyTorch (multi-GB). Not used; faster-whisper covers the same job with CTranslate2 and far less disk.
7. **Gemini vision via Google AI Studio** (`GOOGLE_AI_STUDIO_KEY`, free tier, project "11Players"): `generateContent` accepts up to several inline JPEG frames per call; used to describe 6 evenly spaced frames and to write takeaways/product ideas. Headless: yes. Limits: free tier rate limits (retry on 503), image size and per-request token caps, key must stay server-side (it is, in `_local/api-keys.env`).
8. **Instaloader / gallery-dl**: not installed. Both are GPL (gallery-dl) / MIT (instaloader) scrapers aimed at downloading Instagram media, not understanding it; they duplicate what yt-dlp already does and add login fragility. Skipped.
9. **TikTok-Api and similar public repos**: unofficial wrappers around TikTok's private API, break often, ToS-grey, need ms_token/cookies. yt-dlp already extracts TikTok video+audio without them; skipped.
10. **Chosen pipeline** (`scripts/video_digest.py`): yt-dlp download (cookies-from-browser chrome only as a retry, never printed) -> ffmpeg audio + 6 frames -> Groq whisper-large-v3-turbo, fallback faster-whisper base -> Gemini vision scene notes + takeaways/ideas -> `_local/videos/<id>/digest.md`. Everything private stays in `_local/` (gitignored); nothing from videos enters git.

## Verified end to end (2026-11-12, this PC)

- Local 6 s test mp4 (ffmpeg testsrc + sine): full run 28 s, digest 2,731 bytes, Groq transcript + Gemini scene notes/takeaways/product ideas all populated. Groq needed a browser User-Agent header (bare urllib got Cloudflare 403 error 1010).
- YouTube "Me at the zoo" (19 s, public): download + digest 3 m 33 s total; Gemini 3.6-flash returned 503 twice (retried, then succeeded), digest 2,680 bytes with accurate transcript, 6 scene descriptions and product ideas.
- Gemini model reality on this key (project "11Players"): `gemini-2.5-flash` and `gemini-2.5-flash-lite` now return 404 "no longer available to new users"; `gemini-3.8-flash` hangs past 150 s; working defaults are `gemini-3.6-flash` then `gemini-3.5-flash` (both ~2-3 s on text). Script chain: `gemini-3.6-flash,gemini-3.5-flash,gemini-flash-latest`, override via `VIDEO_GEMINI_MODELS`.
- faster-whisper fallback verified: `C:\Users\a7med\AppData\Local\Python\bin\python.exe` + `base` model (already cached) transcribed the test clip; empty-speech clips correctly return empty text. The PATH `python` (msys64 3.14.7) has no faster_whisper, so the script tries the known interpreter first, then `sys.executable`.
- Batch mode verified: finished digests are skipped (`digest already exists`), failures do not stop the queue, final line reports real counts.
