Root cause measured in the DOM: the panel's parent chain contains
{"tag":"DIV","cls":"rise","transform":"matrix(1, 0, 0, 1, 0, 0)"}
(src/app/[lang]/template.tsx:3 `<div className="rise">{children}</div>`), which is the
containing block for the panel's `position: fixed`. The panel is therefore laid out at the
bottom of the page-long wrapper and `messagesEndRef.scrollIntoView` scrolls the document,
not the message list.
