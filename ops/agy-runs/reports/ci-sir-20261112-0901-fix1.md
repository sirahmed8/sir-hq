## 2. Shared-L4 – clipped text at mobile widths (root causes fixed)

Reproduced first: `test_no_clipped_text` failed at 320px light. A Playwright probe counted clipped `h1,h2,h3,p,span,li,td` elements: **173 at 320px, 27 at 390px, 17 at 768px, 21 at 1280px**. Root causes found and fixed in `plans/dashboard_template.html` + the matching `dashboard_template_*.html` partials (edits applied identically to both so the byte-identical concat contract holds):

1. **Stat tiles forced 4 columns at any width** – `dashboard_template_js3.html` set `$("#tiles").style.gridTemplateColumns = repeat(N,1fr)` inline at load time (desktop viewport), overriding all `@media` rules forever. Replaced by CSS-only `repeat(auto-fit, minmax(min(110px, 100%), 1fr))` on `.tiles` (css3): adapts to tile count AND container width, resize-safe, media queries (2 cols ≤900/≤600, 1 col ≤360) still win.
2. **`.big` numbers clipped vertically everywhere** – `font: 700 28px/1` gave line-height equal to font size; the data font's glyph box is ~1.14em → `scrollHeight 32 > clientHeight 28`. Changed to `/1.25` (also fixes the 18px timestamp variant).
3. **`.checklist-item` crushed to ~0px width** – `.list li` (specificity 0,1,1) beat `.checklist-item` (0,1,0), so handover checklist items rendered as `grid-template-columns: auto minmax(0,1fr)` and the description `.sub` divs were squeezed to 0–7px. Renamed selector to `li.checklist-item` (specificity tie, later in source → flex column wins).
4. **3rd+ children of `.list li` blew out the auto column** – autopilot worker `<li>`s have 3 spans (pill, count, description); auto-placement put the description in row 2 of the `auto` column, stretching it to ~245px and squeezing column 2 to ~1px. Added `.list li > *:nth-child(n+3) { grid-column: 1 / -1; }`.
5. **`.num`/`.mono` could not wrap** – `display:inline-block` (for bidi isolation) made `D:/Projects/SIR Study`-style folder labels unbreakable inside the ~108px column. Scoped override `.list li .num, .list li .mono { display: inline; }` (bidi rules retained).
6. **"MODEL COOLING DOWN" pill overflowed** – `.pill` is `inline-flex; white-space:nowrap`; at 9.5px it is ~117px > 108px column. Added `.list li .pill { display: inline-block; white-space: normal; }`.
7. **`.ms li` milestone rows** – `grid-template-columns: 24px 1fr` let long `<code>` task ids force the track past the container. Changed to `24px minmax(0, 1fr)` + `overflow-wrap: anywhere`.
8. **`.copy-badge`** – `inline-flex` folder path could not wrap (+4px clip at 1280px too). Changed to `inline-block` + `overflow-wrap: anywhere`.
9. **`.truth-card p`** – long backtick-quoted paths (`packages/ui/src/island/SpringIsland.tsx`) overflowed (+4px at 1280px). Added `overflow-wrap: break-word`.
