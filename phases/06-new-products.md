# Phase 6 — New products from TickTick

> **Read first:** `START_HERE.md`, then `core/06-portfolio.md`, `standard/project-templates.md` (PRODUCT.md) and `standard/21-product-essentials.md`. **When this phase is done:** add an entry to `ops/MISSION_LOG.md`, update `ops/HQ_CHECKPOINT.md` and `REQUIREMENTS.md`, send the short report (`core/07-reporting.md`), and continue with a Phase 5 wave for each new product.

For each approved new product:

- Create `D:\Projects\<Product>\` with the SIR file set, `.sir/project.yml`, and a **very detailed** `docs/PRODUCT.md` (template in Part B).
- Plan AI first: PRODUCT.md names the flagship AI feature, the assistant's actions, each feature's data class and its provider chain (module 10), plus the benchmark against the leading apps (module 21).
- Set `CHECKPOINT.md` to "Planned".
- Create the Desktop folder with shortcuts and the folder icon.
- Scaffold code from the template only when the product's wave starts.
