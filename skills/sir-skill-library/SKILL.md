# SIR skill library (one entry point for every skill on this PC)

Do not wait for the owner to name a skill. Search the library yourself.

1. Search the index: `D:/Projects/_SIR/ops/SKILLS_INDEX.md` (385 unique skills: name, which tools have it, category, purpose). Use grep on keywords from the task.
2. Read the real understanding summary: `D:/Projects/_SIR/ops/encyclopedia/deep/<skill-name>.md` (when it exists; otherwise the older digest linked in the index).
3. Then open the original SKILL.md (path in the digest, field Source) and follow it exactly for the task.
4. For MCP servers, connectors and plugins: `D:/Projects/_SIR/ops/encyclopedia/ORGANIZATION_PLAN.md` (sections 6 and 7) and `D:/Projects/_SIR/ops/encyclopedia/mcp-inventory.json` list what each tool has. Never copy tokens or keys out of those files.
5. If a skill exists in several tools with different revisions, the deep summary says which revision is best; use that one.
6. New skill, plugin or connector added anywhere? Add its row to the index and write its deep summary the same day, so no tool ever has a duplicate or an unknown copy.

Rules: AHome and Habiba data never go to outside AI; no secrets in outputs; read only what the task needs.
