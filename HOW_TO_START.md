# How to start (for Ahmed)

1. Put this whole folder at `D:\Projects\_SIR\`, so this file is `D:\Projects\_SIR\HOW_TO_START.md`.
2. Open a terminal in `D:\Projects` (not inside a project) and run `claude`.
3. Type `/model sonnet`, then `/effort high`.
4. Send: `Read D:\Projects\_SIR\START_HERE.md and follow it.`
5. Leave it running. Once Phase 1 fixes Remote Control, you can follow and continue every session from your iPhone.

That's all. You never paste prompts into projects: each project's `AGENTS.md` is its prompt, and the main session starts the project sessions itself.

## Good to know

- **A session gets slow or confused:** type `/clear`, then `continue`. The memory hook reloads the checkpoint, and the agent picks up exactly where it stopped.
- **You want something changed or added:** write it in `D:\Projects\_SIR\ops\IDEAS_INBOX.md`, or in the TickTick list "Inbox for Claude". It becomes a row in `REQUIREMENTS.md`, so it's never lost.
- **Your only list:** `D:\Projects\_SIR\ops\OWNER_ACTIONS.md` holds the few things only you can do (2FA codes, identity checks). Nothing waits for them.
- **How many at once:** one main session until the shared platform and the first product are done, then 2 projects at a time. More sessions share the same usage allowance, so they hit the limit sooner without finishing faster.
- **Usage limits:** the session pauses at the limit and continues by itself after the reset. Nothing is lost, because the checkpoint is saved after every step.
