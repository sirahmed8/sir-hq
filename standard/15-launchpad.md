# 15 — Launchpad: folders, icons, shortcuts, launchers

- **Source of truth:** `D:\Projects\<Product>\`. The Desktop folder `C:\Users\a7med\Desktop\<Product>\` contains **only shortcuts**, never code, builds or copies.
- **Launchers** in `tools/launcher/`: PowerShell scripts with `.cmd` wrappers, each printing what it does and logging to `.sir/logs/`:
  - `start-dev` (menu: web, mobile with emulator, desktop), `run-tests`, `build-installers`
  - `open-editor` (VS Code / Antigravity), `open-claude` (terminal in the project), `open-preview` (live or preview URL)
  - `open-firebase`, `open-github`, `open-checkpoint`
- **Shortcuts:** `.lnk` files created by script (the WScript.Shell COM object): target is the launcher, working directory is the project root, icon is the product's `.ico`.
- **Folder icon:**
  1. Generate `assets/brand/folder.ico` (16, 24, 32, 48, 64, 128, 256 px).
  2. Write `desktop.ini` in the project folder containing `[.ShellClassInfo]` and `IconResource=assets\brand\folder.ico,0`.
  3. `attrib +h +s desktop.ini`, then `attrib +r` on the folder.
  4. Refresh the icon cache (`ie4uinit.exe -show`).
  5. `desktop.ini` is gitignored and regenerated by `tools/launcher/set-folder-icon.ps1`.
- **Icon pipeline** (`sir-icon-pipeline` skill). Masters in `assets/brand/`: `icon.svg`, `icon-foreground.svg`, `icon-monochrome.svg`. Generated outputs:
  - iOS: App Store 1024 px, plus a layered icon with light, dark and tinted variants for Liquid Glass (Icon Composer format; verify the current toolchain)
  - Android: adaptive (foreground, background, monochrome), Wear OS
  - watchOS
  - Windows: `.ico` and MSIX assets; macOS: `.icns`
  - Web: favicon `.ico` and `.svg`, apple-touch-icon, PWA 192/512 maskable, OG image
  - The folder icon
  Every product's icon is unique, and the family shares one visual language.
