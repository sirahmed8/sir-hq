# 09 — Desktop (Windows with the Microsoft Store, and macOS)

- **Electron** (latest stable) + electron-builder. The renderer is the shared web UI built as a static SPA. No apps that just load a remote URL; desktop works offline for its core features.
- **Electron security checklist:** `contextIsolation: true`, `sandbox: true`, `nodeIntegration: false`, `webSecurity` on, strict CSP, typed IPC with every message validated by Zod, no `remote` module, navigation and `window.open` guards, external links opened in the system browser.
- **Integration:** single-instance lock, deep links (`sir<product>://`), tray icon where useful, native menus and shortcuts, system notifications, opt-in launch at startup, remembered window state.
- **Updates:** `electron-updater` from GitHub Releases (or R2/S3), signed, with staged rollout and a channel switch (stable or beta).
- **Data:** local cache with encryption for secrets (`safeStorage`); crash reporting.
- **Windows:** NSIS installer, per-user by default (no admin rights needed). The installer shows the EULA, offers a language choice, creates Start-menu and optional Desktop shortcuts, and uninstalls cleanly (removing app data is opt-in). Direct downloads stay unsigned until a code-signing certificate is affordable, so SmartScreen warns on them (Azure Artifact Signing isn't offered to individuals outside the USA and Canada; an OV certificate is the reinvestment-ladder option). Supports Windows 10 and 11, x64 and ARM64. Older Windows versions cannot be supported by current Electron.
- **Microsoft Store (every Windows app):** publish an MSIX or AppX package (electron-builder's `appx` target, or Electron Forge's MSIX maker) using the identity values from Partner Center (package name, publisher, publisher display name). Microsoft signs Store packages for free and hosts and updates them, so Store users see no SmartScreen warning. Store builds turn off `electron-updater`, because the Store updates them. Run the Windows App Certification Kit before every submission, use package flights for beta testers and gradual rollout for releases, and keep the Store listing current in every locale (module 11). Registration is free for individual developers; Ahmed completes the identity check once. A web-first product may list its PWA through PWABuilder instead: one Store listing per product (ADR).
- **macOS:** universal binary (Apple silicon + Intel), DMG and ZIP, hardened runtime, notarization with a Developer ID (needs the Apple Developer account). Supports the macOS versions the current Electron supports (verify; roughly the last few releases). Built on a macOS CI runner.
- **Test:** clean install, upgrade and uninstall in Windows Sandbox or a VM (if the Windows edition supports it); macOS through CI, plus a manual checklist.
